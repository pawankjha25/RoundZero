# configs/

Role, level, company, and loop definitions - data, not code (see CLAUDE.md decision 2).
Adding a new loop should mean adding a file here, not touching orchestration code.

- roles/     - role family definitions (not created yet)
- levels/    - level definitions (not created yet)
- companies/ - company archetype/style definitions (not created yet)
- loops/     - concrete loop templates, e.g. principal_ml_infra.yaml
